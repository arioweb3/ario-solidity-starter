## 🌐 About

ARIO Solidity Starter demonstrates the fundamentals of storing and retrieving data with a Solidity smart contract.

## ✨ Features

- Store a numeric value.
- Retrieve the stored value.
- Emit an event when the value changes.
- Simple and readable Solidity code.

## 🛠️ Technology

- Solidity `^0.8.20`
- Ethereum Virtual Machine (EVM)
- GitHub
